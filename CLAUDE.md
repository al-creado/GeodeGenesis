# Geode Genesis: rules for Claude

Cozy mobile gacha sim for Android. Angular (standalone, signals, strict TS) + Capacitor. See README.md for the full design summary and stage plan.

## Workflow
- Work in stages (README). Finish and test a stage, then STOP and summarize before starting the next.
- Ask the user before any big decision not covered by the README/spec.
- Node >= 22.22.3 or 24 is required by the Angular CLI. Tests: `npm test -- --watch=false` (Vitest via `ng test`).

## Architecture rules (do not break)
1. **Pure pull logic.** `src/app/core/` has NO Angular/Capacitor/rxjs imports (enforced by `purity.spec.ts`). All randomness goes through the injectable `Rng` (`core/rng.ts`) so tests are deterministic.
2. **One config object.** `core/config.ts` (`GAME_CONFIG`) holds every number: costs, odds, luck, caps, pity, rewards, goals, milestones, shop prices, unlock rules, shard values. Never hard-code these elsewhere (UI text must read from config too). Logic functions take `config` as a defaulted parameter so Remote Config (Stage 5) can override.
3. **Services** (`src/app/services/`): `GameStateService` (signals), `PullService`, `AdService`, `SaveService`. Screens talk to services, not to localStorage/AdMob directly.
4. **SaveService is an interface.** localStorage first, Firebase in Stage 5. Save format carries a `version` number (`GAME_CONFIG.saveVersion`) with migrations.
5. **AdService is an interface** with two implementations: AdMob (Google TEST ad unit IDs only, Android app) and NoAds (browser and anywhere AdMob is missing). There is no custom or fake ad screen. The UI shows ad buttons only while `AdService.available()` is true and the ad settings only when `supported` is true. A reward is granted ONLY after the reward callback fires.
6. **Ads never change pull odds.** Ads multiply coin rewards (login-calendar coins and the post-pull bonus) and shorten the free-pull wait, nothing else. Show "Ads are optional and never change your pull odds" wherever ads are offered.
7. Unit tests for all game logic.

## Injection tokens (src/app/services/tokens.ts)
`CONFIG` (active GameConfig), `CLOCK` (now in ms) and `RNG` are injectable so tests and Remote Config can swap them. Components read numbers from `GameStateService.config`, never from literals.

## Cloud (Stage 5)
Firebase JS SDK (lazy-loaded) behind `CloudBackend` (`services/cloud-backend.ts`); `FIREBASE_CONFIG = null` means local-only. Save is v2 (`savedAt`); newest save wins (`core/cloud-sync.ts`). Remote Config overrides are validated in `core/remote-config.ts` and can never touch ad ids, save version, level cap or slot counts. Setup: `docs/firebase-setup.md`.

## Polish added before release
Save settings carry `introSeen` and `cloudSave`. Android back button logic is pure (`core/navigation.ts`) and wired by `BackButtonService`. `npm run sim` runs the economy simulation (`core/simulate.ts`) and accepts a Remote Config JSON to try numbers. Cloud data can be deleted in-app (`CloudSyncService.deleteCloudData`).

## Release (Stage 6)
Checklist and drafts live in `docs/release/`. AdMob ships with Google TEST ids and `ads.admob.useTestAds: true`; a unit test fails if ids and the flag disagree. Signing secrets (`android/keystore.properties`, `*.jks`) are git-ignored and must never be committed. Store art and launcher icons are generated by `npm run assets` from the game's own SVG art.

## Game rules (quick reference)
- Currencies: **coins** (pulls), **shards** (duplicate at max level, goals, rewards), free **x10 tickets**. Never call coins "gems"; gems are the characters.
- It is a pure gacha: there is no idle or tap income. Pulls come from coins, the free first pull, a free pull on a timer, and tickets.
- Luck = crew gems (each gem's luck grows 10% of its base per level above 1) + completed-set bonuses + claimed collection milestones, capped at +15%. Every non-Quartz weight x (1+luck), then ALL weights renormalized to 100%. At +3.5% luck: Quartz 59.17, Amethyst 28.58, Emerald 9.19, Ruby 2.55, Diamond 0.51 (unit test).
- Pity: Emerald+ guaranteed at 10 pulls, Ruby+ at 50; each counter resets when that tier or better drops (Ruby+ resets both). Ruby wins if both fire. Spark and exchange never touch pity.
- Free pull: comes back after `freePull.cooldownMs` (4h). The wait is shortened by crew gems (passive, `timerReductionPerGem`, grows with level, total capped at `freePull.maxReduction`), by a rewarded ad (`adReduceMs`) and by spending shards (`shardCost` for `shardReduceMs`). Quartz gems have no timer effect.
- All gem stats (luck, timer cut) are exact and fixed by rarity and level. Nothing about a gem is rolled; the gem preview card shows exact numbers and the crew total before and after.
- Duplicates level a gem to 10; beyond that they convert to shards.
- Spark: every 150 pulls (any pull counts) choose any gem. Exchange: shards buy a gem you have not found (price by rarity).
- Login calendar is forgiving (a missed day never resets it). Daily and weekly goals reset at local midnight / Monday.
- Tabs unlock by progress (`core/unlocks.ts`, config `unlocks`); the Settings and Rates screen always shows full odds and rules.
- Crew slots 4 and 5 are unlocked with shards (costs in `crew.slotUnlockShards`).
- The post-pull coin bonus applies to paid pulls only; a rewarded ad adds the extra multiple. Ads multiply only the coins of the login calendar and that bonus.
- Save is v5. Goals, milestones, set bonuses, level luck, passive timer cuts and unlock rules are fixed in code and never remotely overridable. The tabs are Daily, Pulls, Vault, Crew (Pulls is the home tab, route `/pulls`).

## Art and style
- No image assets. The gold lottery machine on Pulls is also drawn in code (`ui/gold-machine`): it is a skin for the normal pull, with the same odds, costs, pity and crew luck. Do not give it its own odds without asking (rate-up banners are out of scope for v1). Gems are SVG generated by a `GemArt` component seeded by gem id. Outline #24160F, stroke 2.5. Palette and rarity frames are in the README.
- Cave theme: bg #2A1C14, cards #3E2A1E / border #5C402D, nav #1E130D, stalactites #1C120C, text #F6E7D0, muted #CDB397, primary button gold #F2B84B (text #24160F), ad button amber #E8833A (text dark). Font Nunito 700/800. Keep accessible contrast.

## Out of scope for v1
Battles, PvP, story, hand-drawn art, real-money purchases, rate-up banners, seasonal events.
