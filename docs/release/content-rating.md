# Play Console: content rating (IARC) questionnaire (draft answers)

Answer the questionnaire honestly in Play Console; the rating is computed from your answers, so what follows is a guide, not a promise of a particular rating.

| Topic | Answer | Why |
|---|---|---|
| Category | **Game** | |
| Violence (cartoon, fantasy, realistic) | None | No combat, no characters being harmed |
| Blood or gore | None | |
| Sexual content or nudity | None | |
| Profanity or crude humor | None | |
| Controlled substances (drugs, alcohol, tobacco) | None | |
| Fear / horror themes | None | |
| User-generated content or user interaction (chat, sharing, social) | None | No chat, no multiplayer, no sharing between players |
| Shares the user's location with others | No | |
| Allows users to purchase digital goods | **No** | No in-app purchases exist |
| Gambling or simulated gambling (casino-style games, real or virtual currency betting) | **No** | There are no stakes: coins come from idle income, a daily bonus and optional ads, and cracking a geode is not a wager. |
| Random-item mechanic ("loot box" / gacha) | Disclose if the questionnaire asks | Cracking a geode gives a random gem. It uses only in-game coins; there are no real-money purchases. The odds and pity rules are shown in Settings and Rates. |
| Contains ads | **Yes** (declared separately in App content) | Optional rewarded ads |

If a question about "simulated gambling" is ambiguous, read Google's and IARC's current definition and err toward disclosure. The game's mechanic is a free gacha with published odds, not casino-style betting.

## After rating
- Expect an "Everyone"/PEGI 3 style result with an interactive-elements note for ads. If the random-item mechanic raises it, accept the computed rating.
- The target audience page is separate from the rating: see `release-checklist.md` section 2.
